# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

L&A Fruver: a produce business web app — a public customer order form (`cliente.html`) and an admin panel (`admin.html`: orders, catalog, suppliers, purchases, invoicing, customers, reports). All UI text, code comments, commit-facing docs and test names are in **Spanish**; keep new code consistent with that.

The project is mid-migration, organized in phases (see README "Riesgos pendientes"):
- **Phase 1 (done):** Express serves static files; pages talked directly to Supabase. Supabase (`@supabase/supabase-js`, `supabase-client.js`, its CSP origin) has been **removed**.
- **Phase 2 (in progress):** own **MySQL** database + server-side API with transactions (schema reference: `tables.sql`, written for Postgres/Supabase — must be translated). Until the API exists, `public/js/admin.js` and `cliente.js` still contain `sb.from(...)` calls that now throw (`sb` is undefined); these must be replaced with `fetch` calls to the new API. The admin panel is protected only by Caddy `basic_auth`.
- **Phase 3:** own login with roles. Phase 5: backups.

Code marked `TEMPORAL (fase 1)` is meant to be removed in a later phase.

## Commands

Requires Node.js >= 24.

```bash
npm ci              # install
npm run build       # copy vendor libs + fonts from node_modules into public/vendor and public/fonts (required before start/test)
npm start           # http://localhost:3000
npm run dev         # node --watch
npm test            # node:test over test/**/*.test.js
npm run audit       # npm audit --audit-level=high
node --test test/server.test.js                              # one file
node --test --test-name-pattern="cabeceras" test/server.test.js   # one test by name
```

Browser tests (`test/browser.test.js`) use `puppeteer-core` with a locally installed Chrome/Edge (override with `BROWSER_PATH=...`); they are skipped automatically if no browser is found.

Deploy: `docker compose up -d --build` on the VPS (app + caddy). Secrets in `.env` are created on the server by `scripts/setup-secrets.sh`; never create or edit a real `.env`.

## Architecture

- `server/app.js` exports `createApp()` (used by both `server/index.js` and tests, which listen on port 0). It sets a strict helmet CSP, serves `public/` with `extensions: ['html']`, `/healthz`, and a generic error handler that never leaks details.
- `server/config.js` holds non-secret config. CSP `connect-src` is `'self'` only, so the frontend may only call this same server.
- Frontend is plain scripts (no bundler, no modules) loaded in order via `<script src>`: vendor libs → `js/common.js` → page script. Functions are shared as globals.
- `.npmrc` sets `allow-remote=root`: npm 12 otherwise refuses `xlsx`, which is installed from a cdn.sheetjs.com tarball URL.
- `public/vendor/` and `public/fonts/` are generated by `scripts/copy-vendor.js` and gitignored. To add a browser library, add it as a devDependency and to `VENDOR_FILES` in that script — no CDNs.
- Docker: multi-stage build, non-root, read-only FS, `cap_drop: ALL`. Only Caddy publishes ports; the app is reachable only on the internal `web` network.

## Rules enforced by tests / security design

- **All dynamic HTML must go through `html\`...\`` + `setHtml`/`appendHtml` from `common.js`**, which auto-escape interpolated values. Never assign `innerHTML` with raw strings. Browser tests feed XSS payloads through fake data (`FAKE` in `test/browser.test.js`) and fail if anything executes. The order-form and admin-panel tests are skipped (`PENDIENTE_API`) until the MySQL API exists; re-enable them by intercepting the API routes in `openPage`.
- **No inline scripts, no inline event handlers (`onclick=`…), no external script URLs** — CSP is `script-src 'self'` / `script-src-attr 'none'`, and `server.test.js` checks the HTML files. Inline `style=` attributes are allowed.
- Browser tests fail on any page error, console error, CSP violation, or `alert/confirm` dialog.
- Dates: use `localDateKey` / `parseDateOnly` from `common.js` (local Colombia time); `new Date("YYYY-MM-DD")` parses as UTC and shifts the day. Browser tests emulate `America/Bogota`.
- Never add `ports:` to internal services in `docker-compose.yml` (Docker bypasses `ufw`).
- When adding a page/asset that must be password-protected in phase 1, also add its path to the `@panel` matcher in `Caddyfile`.
